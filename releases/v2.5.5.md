# 2.5.5

Normalize every packaged file to 0644 permissions rather than inheriting local source modes. This prevents owner-only source permissions from blocking static assets or metadata on hosting with separate PHP/web-server users. Added an isolated regression using 0600 source files and a permission assertion in every build.

Validation: permissions regression, shared PHPCS, existing PHP tests, packaged PHP syntax, ZIP integrity and complete updater/source correspondence.
